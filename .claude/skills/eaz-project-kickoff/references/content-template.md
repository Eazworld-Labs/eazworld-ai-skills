# CONTENT.md

Copy this to the root of a content-heavy project (marketing sites, stores, schools,
churches) as `CONTENT.md`. It tracks the pages, copy, and media the project needs, who
supplies each, and what state it is in, so the build never waits on missing content or
ships placeholder text by accident. Never put secrets in this file.

## Rules

- Real copy and real photos before a page is called finished; mark placeholders
  explicitly.
- Do not invent testimonials, results, ratings, logos, or statistics.
- Photos: confirm the client holds the rights; record the source.
- Test with the longest and shortest realistic text, and a missing image.
